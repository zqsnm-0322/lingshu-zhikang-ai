# 灵枢智康 AI

> 智能健康管理与医疗辅助平台

## 项目概述

灵枢智康 AI 是一个融合人工智能技术的智能健康管理系统，旨在为用户提供精准、高效、便捷的健康咨询与医疗辅助服务。

### 核心目标

- **智能化健康咨询**：基于大语言模型，提供 7×24 小时的专业健康问答服务
- **个性化健康管理**：根据用户健康数据，生成定制化的健康建议与随访方案
- **医疗资源对接**：连接优质医疗资源，助力分级诊疗与远程医疗服务

### 功能特性

| 模块       | 描述                                 |
| ---------- | ------------------------------------ |
| 🏥 智能问诊 | AI 驱动的症状分析与初步诊断建议      |
| 💊 用药指导 | 药品信息查询、用药提醒与相互作用检测 |
| 📊 健康档案 | 个人健康数据记录与分析管理           |
| 🩺 远程咨询 | 视频/文字远程医疗咨询通道            |
| 📈 数据分析 | 健康趋势分析与风险预警               |

## 快速开始

### 环境要求

- Python 3.10+
- Node.js 18+
- Docker & Docker Compose

### 安装步骤

```bash
# 1. 克隆仓库
git clone <repository-url>
cd lingshu-zhikang-ai

# 2. 安装依赖
pip install -r requirements.txt
npm install

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填写必要配置

# 4. 启动服务
docker-compose up -d

# 5. 访问应用
# 前端: http://localhost:3000
# API: http://localhost:8000
```
